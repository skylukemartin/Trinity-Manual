Insert a template with `Alt + I`, or with `Ctrl/Cmd + P` → **Templates: Insert template**:

| Template | Inserts |
| --- | --- |
| `figure-with-caption` | An image with a caption (replace `filepath`, `description` and `caption`) |
| `mermaid-figure` | A Mermaid diagram with a caption and id, so it becomes a numbered figure |
| `typst-pagebreak` | A page break |
| `typst-begin-exclude` / `typst-end-exclude` | The start or end of a block that's hidden from the PDF |
| `typst-lorem-50` | 50 words of filler text |

The recommended settings also add these hotkeys:

| Hotkey | Action |
| --- | --- |
| `` Ctrl/Cmd + ` `` | Switch between source mode and live preview |
| `Ctrl/Cmd + Esc` | Turn Vim mode on or off (only with the extras installed) |
