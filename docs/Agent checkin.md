## Overview 

The client-server network architecture model is implemented in the communication between HTTP/S agents (otherwise known as egress agents) and the team server. In this model, the external team server acts exclusively as the server, while the egress agent acts as the client 

The egress agent resides inside the victim's internal network, it must initiate all communication across the perimeter boundary to bypass inbound firewall restrictions. It acts as the client by reaching out externally to the team server using standard HTTP or HTTPS protocols
